# ClashTank projectPage

เว็บ HTML/CSS/JavaScript แบบ static ตามภาพร่างที่ตกลงไว้ เปิด `index.html` ได้โดยตรง หรือเปิดผ่าน local server โดยไม่ต้องติดตั้งแพ็กเกจ

## โครงหน้า

- โลโก้กึ่งกลางด้านบน
- กล่องข้อมูลเลื่อนอ่านได้ พร้อมแท็บบทคัดย่อ / ภาพรวม / แนวคิด / ฟีเจอร์ที่ขอบล่าง โดยเปิดบทคัดย่อเป็นแท็บแรก และกดสัญลักษณ์มุมขวาบนเพื่อขยายเนื้อหาในแท็บที่อ่านอยู่
- แกลเลอรีภาพรถจริง 4 ภาพ มีลูกศรและจุดเลือกภาพ
- แผนภาพมือถือ → MQTT → รถ พร้อมเส้นทาง Python/Ollama สำหรับเสียง
- ลิงก์ GitHub, วิดีโอ, หน้าควบคุม และโปสเตอร์
- สมาชิก 5 ช่อง

บนจอคอมขนาดมาตรฐาน หน้าเว็บจัดให้ใกล้เคียงหนึ่งหน้าจอ โดยเนื้อหาในกล่องซ้ายเลื่อนแยกได้ จอเล็กจะเรียงส่วนต่าง ๆ ลงด้านล่าง และแถวสมาชิกเลื่อนแนวนอนได้

## เติมข้อมูล

แก้ `site-content.js`:

- `videoUrl`: ลิงก์วิดีโอจริง
- `posterImage`: รูปโปสเตอร์ เช่น `assets/poster.jpg` กดแล้วเปิด image viewer พร้อมปุ่มขยาย/ย่อ
- `posterFile`: ลิงก์ไฟล์ เช่น `assets/poster.pdf` สำหรับเปิดไฟล์ต้นฉบับ ถ้าไม่มีรูปโปสเตอร์จะเปิด PDF ใน viewer
- `members`: ชื่อ รหัสนักศึกษา หน้าที่ และตำแหน่งรูปสมาชิก เริ่มต้นเตรียมไว้ 5 ช่อง

เมื่อนำรูปหรือ PDF มาใช้ ต้องคัดลอกไฟล์เข้า `assets/` ด้วย ช่องที่ยังว่างจะแสดงสถานะเตรียมข้อมูล ไม่สมมติชื่อหรือสื่อที่ไม่มีจริง

## ไฟล์

`index.html` = โครงหน้าและเนื้อหา, `styles.css` = งานภาพและ responsive, `app.js` = แท็บ แกลเลอรีและ poster viewer, `site-content.js` = ข้อมูลที่เจ้าของโครงงานเติม

ฟอนต์ Anuphan และรูปชิ้นงานรวมอยู่ใน `assets/` แล้ว ไม่พึ่ง CDN ฟอนต์ใช้ SIL OFL ตาม `assets/FONT-LICENSE.txt` รูปเป็นภาพที่เจ้าของโครงงานส่งให้ แปลง HEIC เป็น WebP โดยไม่เปลี่ยนชิ้นงานด้วย AI
